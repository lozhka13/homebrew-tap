# lozhka13/tap

Homebrew casks for [lozhka13](https://github.com/lozhka13)'s apps.

```bash
brew install --cask lozhka13/tap/screenshooter
```

| Cask | App |
|---|---|
| `screenshooter` | [Screenshooter](https://github.com/lozhka13/Screenshooter) — sort macOS screenshots and recordings with one key |
